개인정보처리방침

CalendarWidget · 시행일 2026년 10월 30일

1. 이용하는 정보

  • Google 캘린더 (권한: https://www.googleapis.com/auth/calendar): 캘린더 목록과 일정(제목, 시간, 반복 규칙, 색)을 읽고, 사용자가 위젯에서 만들거나 고치거나 지운 일정을 반영합니다.
  • Microsoft To Do (권한: Tasks.ReadWrite): 할 일 목록의 할 일(제목, 기한, 중요도, 완료 여부)을 읽고, 사용자가 위젯에서 바꾼 내용을 반영합니다.
  • 이름, 연락처, 위치, 기기 식별자 등 그 밖의 개인정보는 수집하지 않습니다.

2. 정보를 쓰는 목적

일정과 할 일을 위젯에 보여 주고, 사용자가 위젯에서 바꾼 내용을 Google 캘린더와 Microsoft To Do에 동기화하는 데에만 씁니다. 광고, 분석, 프로파일링, 판매에는 쓰지 않습니다.

3. 저장 위치

  • 일정·할 일과 로그인 토큰은 사용자의 기기 안에만 저장됩니다 (Windows: %LocalAppData%\CalendarWidget, Android: 앱 전용 저장공간).
  • 앱은 별도의 서버를 운영하지 않으며, 데이터는 기기와 Google·Microsoft 서버 사이에서만 오갑니다.

4. 제3자 제공

사용자의 정보를 누구에게도 제공하거나 판매하지 않습니다.

5. Google 사용자 데이터

CalendarWidget이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 따릅니다.

6. 연결 해제와 삭제

  • 위젯의 "연결 해제"를 누르면 기기에 저장된 로그인 토큰이 지워집니다.
  • 앱을 지우거나 위 저장 폴더를 지우면 기기에 남은 데이터가 모두 지워집니다.
  • 권한은 Google 계정 권한 페이지와 Microsoft 계정 앱 권한 페이지에서도 언제든 철회할 수 있습니다.

Summary (English)

CalendarWidget is a personal calendar and to-do widget for Windows and Android. It accesses Google Calendar (calendar scope) and Microsoft To Do (Tasks.ReadWrite) only to display the user's events and tasks and to sync changes the user makes. All data and sign-in tokens are stored only on the user's device; there is no server, and no data is shared, sold or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: imhwajnn@gmail.com
